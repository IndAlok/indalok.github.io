Prediction of cancer-driving synonymous mutations using spectral / FFT-based features

Dataset demonstration links, in the order to open them.

Project: When EIIP Goes Blind · Computational Genomics and Proteomics

1

EPEL paper

The paper this project builds on. EPEL, an ensemble predictor for driver synonymous mutations, PLOS Computational Biology, 2025.

Show: title and abstract only.

 2

EPEL GitHub repository

The authors' public code and data repository. The README confirms the data is COSMIC and the model combines five tree-based models.

Show: the README and the folder list, then the data folder.

 3

Test dataset: id_test_close7.txt

The test set itself. 998 labelled synonymous variants, 499 positive and 499 negative. Columns: chromosome, position, reference base, alternate base, gene name, label (1 = driver, 0 = passenger).

Show: read one row aloud, for example chr 5, 43245922, C to T, NIM1K, label 1.

Download the raw file

 4

Training dataset: id_train_close7.txt

The training set, same format. 3,826 labelled variants, balanced the same way. Together with the test file: 4,824 variants.

Show: the file and its size, no need to read rows.

Download the raw file

 5

One variant in the genome: UCSC Browser

A real row from the test set in the UCSC Genome Browser on hg19: BRCA1, chr17 position 41,245,466, G to A, label 1, shown in a window exactly 101 bases wide.

Show: the 101 bp window, then zoom out once to the BRCA1 gene.

 6

COSMIC

The Catalogue of Somatic Mutations in Cancer, where the label counts come from. EPEL counted recurrences in COSMIC v95: at least 7 tumours means positive, exactly 1 means negative.

Show: search AKT1. Full downloads need a free registration, the derived lists on GitHub (links 3 and 4) are what the project uses.

 7

hg19 reference genome: UCSC downloads

The reference sequence source. The file hg19.fa.gz (about 900 MB) sits under goldenPath/hg19/bigZips. The pipeline downloads it once and cuts the 101 bp windows from it.

Show: the Feb 2009 (GRCh37/hg19) section only. Do not start the download.

 8

GENCODE, GRCh37-mapped releases

The gene annotation source. This page lists release 50 mapped to GRCh37 as 50lift37. It provides the gene, the strand and the codon phase for every variant.

Show: the release 50 row in the table.
All resources are public and free. Labels from EPEL on GitHub, genome from UCSC, annotation from GENCODE, counts originally from COSMIC.
